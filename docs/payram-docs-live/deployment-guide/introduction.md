# ✨Introduction

In this section, you’ll explore two ways to deploy your PayRam server using the setup script or Docker. By the end, you’ll be able to install, configure, and launch PayRam securely and efficiently.

## PayRam installation methods[](#payram-installation-methods)

You can set up your PayRam server using one of two deployment methods, each designed to suit different experience levels and setup preferences.

⚡ **Quick Setup**

Use the PayRam script to install, configure, and start accepting payments in under 10 minutes!

[](https://docs.payram.com/deployment-guide/advanced-setup)

⚙️ **Advanced Setup**

Install PayRam on Docker by manually configuring containers, storage, networks, and variables.
