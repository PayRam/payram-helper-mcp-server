# ✨Introduction

The Merchant Guide provides a step-by-step walkthrough to help you set up and manage PayRam for accepting payments.

Each section covers an essential part of the process, starting from onboarding and node configuration, to wallet management, payment link generation, hot wallet setup, and funds sweeping.

Follow this guide in order to ensure a smooth integration and secure payment flow for your business.
